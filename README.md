# 🌱 Little by Little

A friendly, mobile-ready daily habit tracker. No build tools or runtime framework required.

- Daily check-ins, current/best streaks, seven-day previews, and monthly calendars
- Real empty state, habit creation, deletion, and backdated check-ins
- Local persistence, JSON backup/restore, optional private Supabase sync
- Email-code sign-in, row-level security, offline upload queue
- GitHub Pages workflow with automated model tests

See [SETUP.md](SETUP.md) to enable private cross-device sync. Run `npm test` for the core data and streak checks.
